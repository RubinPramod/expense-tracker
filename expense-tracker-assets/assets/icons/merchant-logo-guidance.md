# Merchant and bank logos

The mockups use illustrative logos for visual familiarity. Do not use generated or copied logos as final production assets without checking source and usage rights.

Suggested policy:
1. Default to a generic category icon (food, transport, shopping, bill, income, transfer).
2. If merchant recognition materially improves scanning, add an official or properly licensed logo asset.
3. Store approved raster/vector logos in `assets/merchants/` and `assets/institutions/`, with source and licence notes in a small manifest.
4. Never treat a logo as the source of transaction classification; classification is based on transaction data and user-confirmed rules.
